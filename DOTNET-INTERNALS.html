■ CIL: CPU-independent. Same dll on Mac/Win/Linux.

■ Metadata: types + namespaces. File paths gone — identity = Assembly + Namespace + Name.

■ JIT: compiles per-method on first call, caches.

■ GC: frees new Game() when unreachable. Gen0 (DTO per request) → Gen2 (singleton TokenService). No free().

TS map: tsc → js → V8 ≈ csc → CIL → RyuJIT. Both GC'd.
